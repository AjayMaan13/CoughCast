# Ethics and data terms

DRAFT written by the AI from each dataset's own pages. Ajay: read each licence page yourself, fix anything wrong, and fill every `[ ]`.

CoughCast is a research prototype, not a medical device. No audio from any dataset is committed to this repo (`data/` is git-ignored).

## ESC-50

- **Source:** https://github.com/karolpiczak/ESC-50 (cloned to `data/esc50`).
- **Licence:** Creative Commons Attribution Non-Commercial (CC BY-NC 3.0) for the dataset; the ESC-10 subset is CC BY. Per-clip attributions are in the repo's LICENSE file. Non-commercial: fine for a public portfolio repo that does not redistribute the audio.
- **Cite:** K. J. Piczak, "ESC: Dataset for Environmental Sound Classification", Proc. 23rd ACM Conference on Multimedia, 2015. DOI 10.1145/2733373.2806390.

## COUGHVID

- **Source:** https://zenodo.org/records/4048312 (`public_dataset.zip`, version 1.0, unzipped to `data/coughvid`).
- **Licence:** CC BY 4.0 as listed on the Zenodo record. Attribution required. The recordings are crowdsourced from volunteers; the metadata includes location and health fields, so do not publish them.
- **Cite:** Orlandic, Teijeiro and Atienza, "The COUGHVID crowdsourcing dataset, a corpus for the study of large-scale cough analysis algorithms", Scientific Data, 2021. [ ] check the volume and article number.
